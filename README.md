# TestHaqeqLabs – QA Automation Framework

## 📌 Overview
Automation testing framework built using Python for UI and API testing.

## 🛠 Tech Stack
- Python
- Selenium
- PyTest
- REST Assured / Requests
- Allure Reports
- GitHub Actions (CI)

## ⚙️ Features
- Page Object Model (POM)
- Reusable utilities
- Automated UI & API tests
- HTML / Allure reporting
- CI execution using GitHub Actions

## ▶️ How to Run
1. Clone the repository
2. Install dependencies
3. Run tests using PyTest

## 📊 Reports
Screenshots / Allure reports are generated after execution.

## 🎯 Purpose
This project demonstrates real-world QA automation practices.
